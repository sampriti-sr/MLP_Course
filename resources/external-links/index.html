    • NumPy Cheat Sheet (DataCamp): Array math, slicing, and shapes.
    • Pandas Cheat Sheet (Official): Reshaping, subsetting, summarizing data.
    • Scikit-Learn Algorithm Cheat Sheet (Official): Interactive roadmap for choosing the right estimator based on dataset size and problem type.

    🎮 Interactive Visualizers & Sandboxes

    • Scikit-Learn Example Gallery: Hundreds of real code recipes comparing decision boundaries, classifiers, and clustering.
    • Seeing Theory (Brown University): Visual introduction to probability, Bayesian inference, and regression.
    • Distill.pub: Interactive, clear visual explanations of machine learning concepts and neural networks.
    • TensorFlow Playground: Interactive browser playground for visualizing neural network decision boundaries in real time.
